YouTube ながら見（Picture-in-Picture 試験）

試験用。YouTube IFrame Player API ＋ Document Picture-in-Picture API のデモ。

対応ブラウザ：Chrome / Edge 116+（Document Picture-in-Picture API）。Safari / Firefox は未対応。
※ http://localhost か https でアクセスしてください（PiP API はセキュアコンテキスト必須）。
※ YouTubeのバックグラウンド再生は本来Premium機能です。本アプリは学習・検証用（非販売）の前提です。
